更新網站步驟（本地模式）

  1. 按上方的「儲存到網站」 — 資料與照片都會自動寫入專案
  2. 在終端機輸入 npm run deploy 上傳網站

覆蓋前會自動備份到 .manage-backups/，改壞了可以復原。

更新網站步驟

  1. 把圖片和 PDF 放到 public/portfolio/ 資料夾
  2. 複製上方程式碼，貼到 src/portfolioData.js 取代全部內容
  3. 開啟 PowerShell，依序輸入：
cd C:\Users\calvi\Desktop\portfolio
git add .
git commit -m "更新作品集"
git push
npm run deploy

等 1-2 分鐘，重新整理網站即可看到更新
