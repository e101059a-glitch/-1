作品集管理工具

新增、編輯作品後，按「下載 data.json」更新網站資料

本地模式 — 按「儲存作品」就會自動寫進 public/portfolio/data.json， 照片也會直接存到 public/portfolio/。
不用下載、不用搬檔案。右邊按鈕是手動再存一次用的。
自動儲存 — 資料會存在瀏覽器裡，關掉再打開不會消失

如何更新網站？（本地模式，只要 2 步）

  1. 在這裡新增或編輯作品，按「儲存作品」（會自動寫進專案）
  2. 到終端機輸入 npm run deploy

資料與照片都會自動寫進專案，覆蓋前會備份到 .manage-backups/。

如何更新網站？（只要 3 步）

  1. 在這裡新增或編輯作品
  2. 按上方「下載 data.json」，把下載的檔案拖進
    Desktop\portfolio\public\portfolio\ 資料夾取代舊檔案
  3. 開終端機，輸入 cd C:\Users\calvi\Desktop\portfolio 再輸入 cmd /c "npm run deploy"

有上傳照片的話，副檔名會變成 .webp，請一併按「下載壓縮後的照片」， 解壓縮後放進 public/portfolio/，不要直接搬原始照片。

想省掉搬檔案的步驟，可以改用 npm run manage 開啟這個工具。
